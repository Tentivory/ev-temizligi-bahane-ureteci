# Evrenin En Gelişmiş Ev Temizliği Bahane Üreticisi

## Proje Hakkında (Aşırı Ciddi Versiyon)

Bu proje, insanlığın en büyük sorunlarından biri olan **"ev temizliği yapmak zorunda olma"** krizine kesin çözüm getirmek amacıyla geliştirilmiştir. 

Kuşantum bilgisayarlar, yapay zeka (GPT-99), uzaydan gelen veriler ve annelerin öğütleri kullanılarak hazırlanan bu sistem, kullanıcıya **bilimsel temelli, duygusal olarak ikna edici ve hukuki olarak geçerli** bahaneler üretir.

**Dikkat:** Bu programı kullandıktan sonra temizlik yaparsanız, evren sizi yargılar. Lütfen sorumluluk sahibi olun.

## Özellikler

- ✨ Rastgele, abartılı ve tamamen işe yaramaz bahaneler üretir
- ⏳ Kuşantum hesaplama simülasyonu (gerçekte 2.5 saniye bekleme)
- 🐱 Kedi, toz, arkeoloji ve çevre bilinci temalı gerekçeler
- 🚫 Asla temizlik yapmanı önermez
- 🌍 Evren onaylı çıktılar

## Kurulum ve Kullanım

```bash
# Python 3 gereklidir (evrenin geri kalanı opsiyoneldir)
python bahane_ureteci.py
```

Program size kaç bahane istediğinizi sorar. Cevap vermezseniz 1 tane verir. 10'dan fazla isterseniz evren sizi uyarır.

## Örnek Çıktı

```
==================================================
   EVRENSEL TEMİZLİK BAHANE ÜRETİCİSİ AKTİF
==================================================
Kuşantum hesaplamalar yapılıyor.....
Hesaplama tamamlandı!

✨ Bahane #1: Bu dağınıklık aslında minimalist sanat eseridir, çok avangart.
----------------------------------------

Sonuç: Temizlik yapmana GEREK YOK. Evren seni onaylıyor.
```

## Katkıda Bulunma

Yeni bahaneler eklemek istiyorsanız, lütfen Pull Request açın. Ancak şunu unutmayın: Bu proje **temizlik karşıtı** bir manifestodur. "Temizlik yapalım" diyen PR'lar otomatik olarak reddedilir ve evrene şikayet edilir.

## Lisans

Bu proje "Asla Temizlik Yapma" lisansı altındadır. İstediğin gibi kullan, dağınıklığını paylaş, ama temizlik yapma.

## Teşekkürler

- Tüm dağınık evlere
- Hayali kedilere
- Tozlara (siz olmasanız bu proje olmazdı)
- Anneme (ama asla temizlik yapmadığım için)
